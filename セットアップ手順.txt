============================================================
  農薬適用作物検索アプリ  セットアップ手順
============================================================

【動作環境】
  - Windows 10/11
  - Python 3.10 以上（https://www.python.org/downloads/）

------------------------------------------------------------
■ STEP 1：依存パッケージのインストール（初回のみ）
------------------------------------------------------------

コマンドプロンプト（または PowerShell）を開き、
このフォルダに移動してから以下を実行：

  cd "（このフォルダのパス）"
  pip install -r requirements.txt
  playwright install chromium

  ※ pip が使えない場合は
      py -m pip install -r requirements.txt
      py -m playwright install chromium

------------------------------------------------------------
■ STEP 2：アプリの起動
------------------------------------------------------------

  streamlit run app.py

ブラウザが自動で開きます（http://localhost:8501）。
開かない場合は上記 URL をブラウザで直接開いてください。

------------------------------------------------------------
■ STEP 3：初回データ取得
------------------------------------------------------------

1. 左のサイドバーにある「🔄 全農薬を再取得」ボタンをクリック
2. 全農薬（14品目）の適用表を農薬登録情報サービスから取得します
   （各農薬を順番にスクレイピングするため数分かかります）
3. 取得完了後、作物名を入力して検索できます

------------------------------------------------------------
■ STEP 4：農薬を追加するには
------------------------------------------------------------

1. 「在庫表 - 農薬クロード用.csv」をExcelやメモ帳で開く
2. 新しい農薬名と登録番号を1行追加して保存
3. アプリで「📥 未取得のみ取得」をクリック
   → 追加した農薬だけデータを取得します

------------------------------------------------------------
■ ファイル構成
------------------------------------------------------------

  pesticide_app/
  ├── app.py                        ← アプリ本体（Streamlit）
  ├── scraper.py                    ← スクレイパー（Playwright）
  ├── requirements.txt              ← 依存パッケージ一覧
  ├── 在庫表 - 農薬クロード用.csv  ← 農薬リスト（編集可）
  ├── pesticide_cache.json          ← 取得済みデータ（自動生成）
  └── セットアップ手順.txt         ← このファイル

------------------------------------------------------------
■ トラブルシューティング
------------------------------------------------------------

● 「No module named 'playwright'」と表示される場合
  → pip install playwright && playwright install chromium

● データ取得中にエラーが出る場合
  → サイドバーの「📥 未取得のみ取得」を再試行
  → インターネット接続を確認してください

● 検索結果が出ない場合
  → 作物名の表記を変えてみてください
     （例：「トマト」→「とまと」、「ミニトマト」なども試す）
  → 登録農薬に適用がない可能性があります
